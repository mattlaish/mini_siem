Host profiles
Use the exact event hostname. Groups select schedules and exceptions; web_server role qualifies java.exe/httpd.exe parents. The host IANA timezone interprets timestamps lacking an offset. Telemetry silence is opt-in: choose a threshold suitable for the expected activity or send regular heartbeat/test events. UDP delivery is not guaranteed.

  
Approved execution windows
Weekdays: Monday=0 … Sunday=6. End time is exclusive. Overnight windows belong to the starting weekday. Dates add approved dates; excluded dates remove holidays. No configured window means Out-of-Hours evaluation is skipped and shown as unconfigured.

  
Rule-specific approved exceptions
Each exception requires a host/group, full executable and parent paths, command pattern, account, approved window, expiry and ticket. The authenticated administrator is recorded as approver when saved. Exceptions cannot exempt Web Server Spawning Shell; raw logs and other rules continue.
