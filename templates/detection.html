Detection rules

Turn rules on or off, adjust how many matching events cause an alert, or add your own conditions. Every condition must match. Choose Windows activity or All log sources. Host profiles
Add a host to apply its time zone, approved hours and exceptions. Use its reported name, such as HMSWEB1 or HMSWEB1.corp.example.com; names from different domains are not treated as the same host. Use groups to share settings. Set the web_server role for Java or Apache web servers. Optionally enable a warning when expected logs stop arriving. Choose a realistic delay: an idle host may produce no events, and UDP delivery is not guaranteed.
Windows hosts without a profile

  
Approved execution windows
Choose the days and times when shell use is approved. Activity exactly at the end time is outside the window. An overnight window starts on the selected day and ends the next morning. Add one-off approved dates or exclude holidays. Without approved hours, the outside-hours rule is not checked for that host.

  
Rule-specific approved exceptions
Approve a specific Windows task by selecting its rule, host or group, program paths, command, account, allowed hours, expiry and change ticket. The administrator who saves the exception is recorded as its approver. Exceptions cannot suppress the web-server rule, repeated-activity rules or All log sources rules. Original logs are kept and other rules still apply.
